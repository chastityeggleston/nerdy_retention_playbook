Consumer Archetypes

Personas

Four parent archetypes behind the segments. Each has a distinct motivation, churn trigger, and save offer. Messaging must match their core need — not a generic value prop.

Outcome Driver

The Outcome Driver

Parent 38–50 · suburban · HHI $120k+ · buys 30-hr tier

Core Need
Measurable grade & score gains
Churn Risk
High if no visible progress by Day 30
Save Offer
Tutor swap + free session · data-led progress report with grade delta
Messaging Angle
Lead with numbers. Show sessions completed, skills mastered, grade improvement. Never lead with warmth — lead with proof.
Rescue Parent

The Rescue Parent

Parent 35–48 · any market · starts 9-hr then upsells

Core Need
Prevent failure, restore confidence
Churn Risk
Medium-high if tutor fit feels wrong
Save Offer
Free tutor swap, no questions asked · early win story from tutor
Messaging Angle
Warmth and reassurance first. One early win from the tutor is worth more than ten data points. Empathy before outcomes.
Busy Optimizer

The Busy Optimizer

Working parent 32–45 · dual income · 15-hr tier

Core Need
Minimal friction, autopilot scheduling
Churn Risk
Medium — seasonal schedule drift
Save Offer
30-day free pause · one-tap reschedule · session reminder push
Messaging Angle
Remove friction from every touchpoint. Short emails. One CTA. Never ask them to do something — do it for them and confirm it's done.
Value Validator

The Value Validator

Parent 30–52 · HHI $60–90k · 9-hr tier

Core Need
Cost-per-session justification
Churn Risk
High — low usage near renewal
Save Offer
Usage boost + one free session · per-session cost breakdown
Messaging Angle
Math only. $58/hr vs $80–120/hr in-person. Show cost-per-session used. Tier upgrade pitch: $2/hr cheaper at 15 hrs, $8/hr cheaper at 30 hrs.
