# Nerdy Retention Marketing Playbook

An interactive retention strategy tool for Nerdy's consumer and district business.

**Live site:** [nerdyretentionplaybook.vercel.app](https://nerdyretentionplaybook.vercel.app)

## What's inside

The playbook is organized into six tabs:

- **Lifecycle** – the customer journey from onboarding through renewal
- **Segments** – key consumer and district audiences
- **Campaigns** – retention programs mapped to each stage and segment
- **Experiments** – tests to validate and improve retention levers
- **Metrics** – the KPIs that measure retention health
- **Personas** – profiles of the people behind each segment
